# Siddhant Gahtori — Portfolio

Personal portfolio website hosted on GitHub Pages.

**Live:** https://imsiddhant.github.io

## Stack
- Pure HTML / CSS / JavaScript — zero dependencies, zero build step
- Canvas API for the animated cloud network background
- Google Fonts (Inter + JetBrains Mono via CDN)

## Structure
```
Portfolio/
├── index.html              # Single-page portfolio
├── siddhantgahtori.pdf     # Resume (linked in nav)
└── README.md
```

## Deploy to GitHub Pages

1. Create a repo named `imsiddhant.github.io` (or any repo name)
2. Push this folder's contents to `main`
3. Go to **Settings → Pages → Source: Deploy from branch → main / root**
4. Live in ~60 seconds at `https://imsiddhant.github.io`

## Features
- Animated particle/cloud network background with AWS service labels
- Typewriter effect cycling through roles
- Scroll-progress bar
- Counter animations on stats
- 3D card tilt on hover (projects + experience)
- Cert filter tabs (All / AWS / Kubernetes / CompTIA / Other)
- IntersectionObserver scroll animations with stagger
- Fully responsive (mobile-first)
- Noise texture overlay for depth
